# Sunny Meng Photography — Static Site

A minimal, elegant photography portfolio that mirrors the provided screenshot:
- Serif logo header with nav
- Two-column vertical gallery
- Two centered CTA blocks ("Testimonials" and "Services")

## How to use

1. Replace the SVG placeholders in `assets/photos/` with your real images (keep the filenames or update `index.html`).
2. Edit text: brand name, email, Instagram, etc.
3. Deploy to GitHub Pages.

### Deploy to GitHub Pages
1. Create a new GitHub repo (e.g., `sunny-meng-photography`).
2. Upload all files in this folder to the root of the repo.
3. In **Settings → Pages**, set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`) → `/root`
4. Wait ~1 minute. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Image notes
- Use portrait JPGs (e.g., 1200–1600 px height). The layout is responsive; one column on mobile, two columns on desktop.
